## Image Preview Guide

This application provides a simple way
to preview images in a browser.

### Main Features
- Local image selection
- Image preview
- File information
- Image dimension display

### How to Use
1. Open the image preview tool.
2. Select an image from your device.
3. Review the image preview.
4. Check the available image information.

### Supported Formats

Common browser-supported image formats
can be previewed.

### Privacy Note

Selected images are processed locally
when the application uses browser-based preview.
## Manual Testing Checklist

- [ ] Select a supported image and inspect its preview.
- [ ] Compare the displayed file size and image dimensions.
- [ ] Clear the image and confirm the preview disappears.
